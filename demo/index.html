Portal Institucional FATEB — Ambiente de Demonstração

Esta página valida o widget flutuante do NIA Chatbot Gemini fora do WordPress.

Como window.niaChatbotConfig não está presente aqui, o script utiliza o modo de demonstração local. Dentro do WordPress, as mensagens são enviadas via POST para /wp-json/nia-chatbot/v1/message com validação de X-WP-Nonce.
